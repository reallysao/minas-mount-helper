# 威胁模型与访问边界（Threat Model）

> 基线 d25c251；本文件只描述威胁、边界与处置要求，不复述任何真实敏感值。
> 修复落点见 `../sdd/requirements.md`（SR-*）与 `../sdd/traceability-matrix.md`。

## 1. 资产

| 资产 | 说明 |
|---|---|
| NAS 文件数据 | 经 P2P 隧道读写的用户文件 |
| WebDAV 凭证（用户名/密码） | 控制代理上游访问 |
| 客户端证书/私钥 | 官方 App 颁发，用于对隧道的客户端认证 |
| 目标快照（端口/代次） | 决定代理连接哪个上游，被回滚会导致 502 |

## 2. 信任边界

- 边界 1：外部网络 ↔ 本机回环。代理只绑 `127.0.0.1`，外部无法直连；但**回环不等于信任**。
- 边界 2：同机其他用户/进程 ↔ 本用户会话。回环端口可被同机其他账户/进程访问，
  必须靠入站认证（SR-1）隔离，不能只靠绑定地址或 600 文件权限。
- 边界 3：本仓库代码 ↔ 官方 P2P 隧道/NAS。隧道内部认证与证书链在仓库外，本仓库不假设、不外推。

## 3. 威胁与处置

| 威胁 | 基线现状 | 处置（需求） | 状态 |
|---|---|---|---|
| T-a 同机进程借代理匿名读写 NAS | 入站认证未被调用，所有请求被注入上游凭证（T01） | 恒 require：缺/错凭证 401+WWW-Authenticate，未配齐 503，绝不匿名转发；无 optional 降级（SR-1） | A 层已验证（B 层实机未验） |
| T-b 凭证硬编码进源码/脚本/命令行 | 根目录历史探针含真实账号密码；app_core 残留带凭证 URL；NetFS/curl 把密码放 argv（P0） | 仓库源码/脚本零硬编码；改环境变量/显式开关，默认拒绝；凭证不走 argv；已暴露凭证视为泄露，**提示所有者轮换/吊销**（SR-2、SR-4） | A 层已验证（根探针与守卫；core 内残留由对应模块维护者处理并在本模型登记） |
| T-c 服务器身份未验证即宣称安全 | `CERT_NONE`+`check_hostname=False`，加载 CA 被误读为校验（T11） | CERT_REQUIRED+主机名校验；`tls_server_name` 必填、`MWDAV_TLS_*` env 优先、不自动学习、回环不豁免；**无 verify=false 跳过开关**；失败 fail-closed；文档不得宣称"确保真 NAS"（SR-3） | A 层已验证（真实设备握手 B 层未验） |
| T-d 超大上传变空文件/破坏 keep-alive | 超限把长度置 0、空体转发（T02） | 413 + Connection: close + 受限排空，禁止空体转发；chunked 写方法显式拒绝（FR-2.6） | A 层已验证（B 层实机未验） |
| T-e 写操作在"已提交但响应丢失"后盲重放 | 异常分支用旧快照重发（T14/D04） | 区分发送前失败/可能已提交；不安全方法不重放，安全方法重试前重载最新代次（FR-2.7） | A 层已验证（B 层实机未验） |
| T-f 旧目标回滚覆盖新端口 | 读状态有副作用 + 多写者（D02）；错误处理回写旧目标（D04） | 读零写副作用；单写者原子发布 + generation；健康不写配置（FR-1.3/1.4、A03） | A 层已验证（B 层实机未验） |
| T-g 误认/误卸其他 WebDAV 卷 | 任意 webdav 卷被认领；mount_dir 字符串即真（T07/T08） | MountIdentity 校验归属，自定义目录实测（FR-3.1/3.2） | A 层已验证（B 层实机未验） |
| T-h 历史发布包夹带/漂移 | 仓库内 v1.4 ZIP 与 HEAD 部分文件不同，含旧代码；源码残留未接入模块 | 不改历史 ZIP；文档如实说明漂移、以 HEAD 为准；发布包带 commit 与校验和（FR-4.3） | 文档说明 |

## 4. 明确不做

- 不轮换、不复制、不在新文件书写历史暴露的真实凭证；只提示所有者处理。
- 不验证官方 P2P 隧道内部安全；不为"通过 mTLS"做超出代码事实的宣传。
- 不在本分支实现 optional 匿名入站；NetFS 不送凭证记为兼容性失败（B-7）。

## 5. 凭证轮换提示（给仓库所有者）

历史根目录探针（`probe_ports.py`、`test_*.py`）与 core 残留中曾出现真实 WebDAV 凭证，
应按**已泄露**处理：在官方 App/NAS 侧吊销或轮换该 WebDAV 密码，并检查对应客户端证书是否需要更新；
本仓库只清理自身可见副本，无法撤回历史提交与旧发布包中的内容。
